# Pong-reinforced-learning-bot
Custom Pygame environment implementing Double Q-Learning in Python with Arduino serial integration and live training telemetry logging.

I had a lot of fun making this project; it really challenged my learning. It was originally meant for studying the way AIs would learn by using real brain matter and neurons, which was replicated utilizing an Arduino 'yes or no' switch. There is an automatic feature so people can utilize both Arduino and non-Arduino functions.
